1. I'd like to create a ramp component in @packages/td-core that renders a TouchDesigner ramp. It only needs to be one direction, from TD -> web. In the touchdesigner config file I want the ability to point at the ramp top, fetch the rampTOP.par.dat plus it's other parameters like phase and send that table over the wire. Then in the Ramp component on the web it should take that table and render a gradient. Start with just a linear horizontal and vertical gradient but in a way where we can support the radial and circular types later. The rampTOP dat has a row for each color stop with columns pos, r, g, b, a all in units from 0->1.

2. Export all my TouchDesigner VJ color ramps as DAT files. Use those files to drive the list of ramps. When a ramp is clicked in the GUI pass the path of that dat to the SceneLoader and have the scene loader render the ramp using that DAT.
